# TS Node Express

Express + TypeScript API starter with Prisma and JWT authentication.

## Features

- JWT auth with permissions
- Prisma ORM
- Validation and rate limiting

## Tech Stack

- TypeScript
- Prisma
- Express

## Getting Started

```bash
git clone https://github.com/ghostland-dev/ts-node-express.git
cd ts-node-express
cp .env.exemple .env   # then fill in your own values
npm install
npm run dev
```

Other scripts:

- `npm run test`: echo \
- `npm run build`: tsc
